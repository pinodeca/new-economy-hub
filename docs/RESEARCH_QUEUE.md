# Research queue

Candidate organizations to run a [`content/RESEARCH.md`](../content/RESEARCH.md)
pass on, in rough priority order. **Nothing here is a content record** — these
are leads, not researched facts, and none of them are in `content/` yet. Each
one still needs the full pass (the org's own claims verified, plus the two
questions: does it run anything with a date, and anything people can join and
talk in) before it becomes a file.

Candidates were compiled 2026-09-09. Every URL below returned a live page on
that date except where flagged. The "already spotted" column is a head start,
not a finding: it's what was visible from the homepage, and it still has to be
confirmed and sourced during the pass.

Delete a line when its org is merged, or when a pass concludes the org doesn't
belong here — with a note saying which, so the same lead doesn't get picked up
again next month.

## Coverage as of 2026-09-09

All 10 current organizations are `geoScope: US`, and 6 of the 10 are worker
co-op / co-op-development orgs. There is no international, UK, Canadian,
Australian, or Indian content at all, so the `INTERNATIONAL` and `COUNTRY`
geo-scopes are currently filters over an empty set — the geography filter bar
renders three buttons, two of which return nothing.
